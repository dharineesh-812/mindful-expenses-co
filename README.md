# Mindful Expenses 💰

A smart personal finance and expense tracking application that helps you spend mindfully with category-based insights and budget goal tracking.

## 🚀 Features

- Add, edit, and delete expense entries
- Category-based expense classification (Food, Transport, Entertainment, etc.)
- Budget goal setting and progress tracking
- Spending insights and visual analytics
- Clean and intuitive dashboard UI
- Fully responsive design

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React.js, TypeScript, Tailwind CSS |
| State Management | React Hooks |
| Charts | Chart.js / Recharts |
| Build Tool | Vite |

## ⚙️ How to Run

```bash
git clone https://github.com/dharineesh-812/mindful-expenses-co.git
cd mindful-expenses-co
npm install
npm run dev
```

## 📊 Key Screens

- **Dashboard** — monthly spending overview with category breakdown
- **Add Expense** — quick entry form with category tagging
- **Budget Goals** — set limits per category and track progress
- **Insights** — visual charts showing spending patterns
